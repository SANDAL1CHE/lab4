# Geometric Lib & Unit Tests

**Geometric Lib** — библиотека для вычисления площади и периметра базовых геометрических фигур, а также проведения тестирования с помощью `unittest`

## Возможности

* **Расчет для прямоугольника:** Вычисление площади (`area`) и периметра (`perimeter`) в модуле `src/rectangle.py`
* **Расчет для квадрата:** Вычисление площади и периметра по длине стороны в модуле `src/square.py`
* **Расчет для круга:** Вычисление площади и длины окружности через константу `math.pi` в модуле `src/circle.py`
* **Расчет для треугольника:** Вычисление площади по основанию и высоте, а также периметра по трем сторонам в модуле `src/triangle.py`
* **Тестирование:** Набор unit-тестов в директории `tests/`, проверяющих корректность вычислений и граничные нулевые значения

## Требования к проекту

1. Интерпретатор **Python 3** (версии 3.6 и выше)
2. Стандартная библиотека `unittest`
3. В корне проекта должны находиться две директории: `src` с исходным кодом модулей и `tests` с тестовыми сценариями

## Использование и команды

* `py -m unittest discover -s tests` (**Запуск всех тестов**): Находит и выполняет все тестовые сценарии в папке `tests/`, выводя общий отчет (`OK` или `FAILED`)
* `py -m unittest tests/test_rectangle.py` (**Точечная проверка**): Запускает тестирование только одного выбранного модуля (например, прямоугольника)

## Инструкция по запуску из исходников

1. Выполнить клонирование репозитория: `git clone https://github.com/SANDAL1CHE/lab4.git`
2. Перейти в директорию проекта: `cd lab4`
3. Запустить полный прогон модульных тестов: `py -m unittest discover -s tests`
